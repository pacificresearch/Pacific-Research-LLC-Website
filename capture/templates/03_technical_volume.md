# Technical Volume / Quote Narrative — outline template

Only produce the volumes the solicitation asks for, in its prescribed
structure. If it prescribes section order, THAT order overrides this
outline. Every section must trace to compliance-matrix rows (cite row
numbers in comments while drafting; strip before submission).

## 1. Understanding of the Requirement
Restate the government's need in its own PWS/SOW language plus one level
of insight (constraints, site conditions, population served) that shows
we read everything including attachments.

## 2. Technical Approach
Mirror the PWS task structure 1:1 (Task 1 → our approach to Task 1...).
For each task: who performs it (PRG staff / named sub), how, to what
standard, and how PRG verifies it (QC).

## 3. Management Approach
- PRG as prime: single POC, contract management, QC, invoicing,
  compliance. Name the PM (founder unless scoped otherwise).
- Staffing/teaming structure: named key personnel with contingent-offer
  letters, or named subs with commitment letters.
- Limitation-on-subcontracting compliance statement where applicable.
- Communication cadence with CO/COR; escalation path.

## 4. Quality Control
Inspection schedule, standards mapped to the PWS performance thresholds
(or QASP if provided), deficiency correction loop, records.

## 5. Key Personnel & Résumés
From `library/resumes/`, tailored to the position descriptions in the
solicitation. Certifications matched to matrix rows.

## 6. Past Performance Volume (if separate)
Per the solicitation's format (often CPARS-style: contract #, value,
period, POC with phone/email, relevance narrative).
