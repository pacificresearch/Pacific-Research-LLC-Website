# Opportunities

One folder per screened-in opportunity:

```
YYYY-MM-DD_<agency-short>_<notice-id>/     # date = response deadline
  00_screening.md
  01_solicitation/
  02_compliance_matrix.md
  03_proposal/
  04_pricing.md
  05_staffing/
  06_submission_checklist.md
  07_award/          # on win only
  99_debrief.md      # on decision, win or lose
```

PASS decisions do NOT get folders — the screening log lives with the
SAM.gov matcher reports. Folder creation is the marker that PRG is
spending effort.

State is tracked in `00_screening.md` header: SCREEN → PURSUE → SUBMIT →
MONITOR → WIN/LOSS. Update it as the opportunity moves.
