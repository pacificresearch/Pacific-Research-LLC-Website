# Past performance records

**The compounding asset.** Past performance is what turns the second bid
into a stronger bid than the first. It is also the thing that is
impossible to reconstruct accurately a year later — so it gets filed
**monthly, as performance happens**, not at contract close.

One file per performance record: `<customer>_<contract-number>.md`.
Founder pre-PRG records (OAW, Stanford trials, USAF) live here too, with
the role stated honestly as individual rather than company performance.

## Record template

```markdown
# <Customer> — <Contract number>

| Field | Value |
|---|---|
| Customer / agency | |
| Contract number | |
| Prime or sub | **Prime** / Sub (name the prime) |
| Total value | |
| Period of performance | start – end |
| NAICS / PSC | |
| CO / COR name, email, phone | |
| Reference contact (if different) | |
| Reference permission obtained | date asked, date confirmed |

## Scope
Five sentences maximum. Solicitations routinely cap reference scope at
this length — write it short here and it pastes straight in.

## Outcome and metrics
Numbers, dated, sourced. Not adjectives.
- On-time delivery rate:
- Quality/AQL performance against the QASP:
- Cost performance vs. award:
- Any award fee, commendation, or CPARS rating received:

## Problems and resolution
State them. A record with no problems reads as unexamined; a record with
a problem and a documented fix reads as a contractor who can be trusted
with the next one.

## Reusable content produced
Link the proposal sections, QC plans, and templates this contract
generated that were filed back into the library.
```

## Monthly filing habit

On the same day each month, for every active contract, append: metrics
to date, deliverables accepted, any deficiency and its resolution, and
any customer comment worth quoting. Ten minutes a month; unrecoverable
if skipped.

## Reference permission

**Ask before listing anyone.** Confirm the contact is still in the role
and still willing, and record the date you confirmed. A stale or
unwilling reference is worse than one fewer reference.
