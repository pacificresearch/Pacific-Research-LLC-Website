# Partner and candidate warm list

Everyone who quoted, committed, or applied on a past pursuit — win or
lose. **A lost bid that leaves three vetted subcontractors behind was not
a total loss.**

One file per partner: `<naics>_<firm-or-person>.md`.

| Field | Value |

| Firm / individual | |
| Type | subcontractor / staffing firm / distributor / 1099 professional / W2 candidate |
| NAICS / capability tags | |

| Credentials held (with expiry) | |

| Responsiveness | how fast they replied, whether they followed through |
| NDA / teaming agreement on file | |

| Last contact | date |
| Verdict | preferred / usable / do not re-engage (state why) |

## Rules

1. **Record rates with their date.** A rate without a date is worthless
   in twelve months.
2. **Refresh anyone you intend to name every 60 days.** Commitments go
   stale; people take other work and stop answering.
3. **Record the rejections too**, with the reason. Checking this list
   before sourcing is faster than re-vetting someone you already ruled
   out.
4. **Flag SDVOSB/VOSB partners explicitly.** On a set-aside, only PRG's
   own employees and similarly-situated entities count toward the 50%
   services floor — that status changes whether a partner solves your
   compliance problem or creates one.
