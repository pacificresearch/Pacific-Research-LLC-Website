# intl/opportunities/

One folder per surviving international pursuit. Folder shape and
contents are defined in `intl/WORKFLOW.md` Stage 0.

Naming: `YYYY-MM-DD_<country>_<buyer>_<notice-id>/`
e.g. `2026-09-04_Peru_StateDept_19PE5026Q0011/`

Nothing gets a folder until it clears `intl/GATE.md`. A
REGISTER–PREPOSITION outcome gets a line in `intl/PIPELINE.md`, not a
folder.
