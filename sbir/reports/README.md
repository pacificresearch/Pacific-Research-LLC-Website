# SBIR/STTR digests

Written by `sbir_sttr_pipeline.py`, one per run, named
`PRG_SBIR_digest_YYYY-MM-DD.md`.

Read them in this order:

1. **The source-health table**, which is deliberately above the ranking.
   Four of the nine sources are routinely unavailable; the table says
   which ones failed today and what was therefore not screened. A digest
   with holes is not a cross-agency sweep and says so.
2. **The ranked shortlist**, capped at 10, ordered by fit × deadline
   feasibility plus a bounded credit for a restricted eligibility field.
3. **The kill ledger.** This is not an appendix. It names the gate that
   fired on every screened-out candidate, and it is where a mis-scored
   row becomes visible.

Every announcement number, deadline, and budget cap carries the URL it
was read from. Anything the run could not verify says `NOT VERIFIED`
rather than carrying a plausible figure.
